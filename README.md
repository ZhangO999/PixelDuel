# Pixel Duel

Pixel Duel is a small local two-player shooter I am making while learning C#
and Unity. Both players share one keyboard and the first player to five points
wins.

This is an early learning project. Expect rough code, placeholder graphics and
bugs while I figure out object-oriented programming and game physics.

## Controls

- Player 1: `A`/`D` to move, `W`/`S` to aim, left Shift to jump, Space to fire.
- Player 2: arrow keys to move and aim, `/` to jump, right Shift to fire.
- `R` returns to the title screen and `Esc` quits.
